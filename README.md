# 磁盘空间管家

Windows 磁盘空间分析与清理工具（Rust 扫描引擎 + Electron 界面）。本仓库只用于发布安装包与校验信息，源码仓库不公开。

## 下载

v0.4.0 计划于 2026-12-04 发布，届时见本仓库 Releases 页面。当前暂无可用下载。

## 版本与签名口径

- v0.4.0 为未签名测试版，Windows SmartScreen 会提示"未知发布者"；下载后请核对 Release 页面给出的 SHA256。
- 计划在 OV 代码签名证书到位后发布 v0.4.1 签名版。
- 除对应版本的 Authenticode 状态为 Valid 外，本仓库不会使用"正式签名版"等表述。

## 安装说明

- 安装包为用户级 NSIS 安装，安装目录 `%LOCALAPPDATA%\Programs\disk-space-manager`，安装过程不需要管理员权限。
- 快速扫描需要管理员权限与 NTFS 文件系统；未以管理员身份运行时，程序会提示并降级为通用扫描模式。
- 删除操作进入回收站，可还原。
